# AI CRM Assistant for Banking CRM

This project is a graduation thesis prototype that demonstrates how an internal AI assistant can support relationship managers, sales staff, and customer service teams in a banking CRM system.

The prototype uses mock CRM data and does not use any real bank data, real customer data, or real MB/MBBank interface.

## Main Features

- **Customer Brief** - AI-powered customer profile summaries
- **Next Best Action** - AI suggests the most appropriate next action
- **Product Suggestion / Next Best Offer** - AI recommends suitable cross-sell/upsell products
- **AI Call Script Generator** - Generate call scripts for customer interactions
- **Call/Meeting Summary** - AI-powered meeting note summarization
- **Follow-up Task Generator** - AI creates actionable follow-up tasks
- **CRM Dashboard** - Overview of KPIs and daily briefing
- **Customer Profile** - Comprehensive customer information
- **Task Management** - Track and manage follow-up tasks

## Tech Stack

- **Next.js** - React framework with App Router
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **Recharts** - Chart library for data visualization
- **Mock CRM Data** - Simulated banking customer data
- **Rule-based Recommendation Engine** - AI recommendation logic
- **Optional AI API Integration** - Can connect to OpenAI later

## Run Locally

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

```bash
# Lint code
```


## Important Note

This is an academic prototype. It is not connected to any real banking system and does not make final credit, financial, or risk decisions.

All recommendations are generated by a rule-based engine for demonstration purposes. In production, AI capabilities can be enhanced with real machine learning models and AI APIs.
